VPS Backup

A personal, self-hosted backup utility. Last updated: October 2026.

What this application is

VPS Backup is a private, single-user tool that backs up the files and databases of one self-hosted virtual private server to that same server operator's own cloud storage. It is not a public service: it has no sign-up, no web front end, and no other users. It exists so that the operator does not lose configuration, source code and database contents if the server's disk fails.

What it does

  • Runs a scheduled job once a day on the server.
  • Collects the server's own configuration files and service data.
  • Creates compressed database dumps of services running on that server.
  • Encrypts everything locally with restic (client-side encryption, content and file names) before anything leaves the machine.
  • Uploads the encrypted, deduplicated snapshots to the operator's own Google Drive storage using rclone.

Use of Google Drive

The application requests exactly one Google OAuth scope: https://www.googleapis.com/auth/drive. It is used solely to create, read and delete its own backup files inside the operator's own Google Drive account. The application does not read, modify, or share any other files in that Drive, and it never accesses any other Google account.

Data sent to Google Drive is already encrypted on the server before upload, so the stored objects contain no readable content. The application does not send Google user data to any third party, does not use it for advertising, and does not use it to train machine-learning models. See the Privacy Policy for details.

Technical summary

  • Client: rclone (Google Drive backend, Desktop OAuth client)
  • Backup engine: restic — deduplication, snapshots, client-side encryption
  • Schedule: daily, operated by systemd timers
  • Operator: one person, on one machine, using one Google account
