Privacy Policy — VPS Backup

Last updated: October 2026

VPS Backup is a private, single-user backup tool operated by one individual for their own self-hosted server. It is not offered to the public and has no users other than its operator. This policy explains what data it handles and how.

1. What Google user data is accessed

The application requests a single Google OAuth scope:

  • https://www.googleapis.com/auth/drive — access to Google Drive files belonging to the operator's own Google Account.

In practice the application only creates, lists, reads and deletes the backup files it created itself, stored in one folder inside the operator's own Drive. It does not read, index, modify or share any other file, and it does not access Gmail, Calendar, Contacts, Photos or any other Google product.

2. How the data is used

  • Purpose: to store encrypted backup snapshots of the operator's own server.
  • The data is used only for that purpose. It is not used for advertising, profiling, marketing or analytics.
  • It is not used to train or improve machine-learning models.
  • It is not shared, sold or transferred to any third party, except as required by law.

3. How the data is stored and protected

  • All backup content is encrypted on the operator's own server before upload using restic (AES-256, with both file contents and file names encrypted).
  • The repository password never leaves the operator's server and is not stored in Google Drive.
  • OAuth credentials (tokens) are stored only on the operator's server with owner-only file permissions.
  • Access to the Google Drive account is protected by the account owner's own Google sign-in, including whatever two-factor authentication that account uses.

4. Data retention and deletion

  • Snapshots are kept on a rotation policy (7 daily, 4 weekly, 6 monthly) and older ones are deleted automatically.
  • All backup data can be deleted at any time by the operator from Google Drive directly, or by revoking the application's access at myaccount.google.com/permissions.
  • Revoking access immediately stops all further use of Google Drive; previously uploaded files remain in the operator's own Drive until deleted by the operator.

5. Limited Use disclosure

VPS Backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Data collection

The application has no server of its own and collects no telemetry, analytics or personal data. No information about any person is transmitted anywhere other than the encrypted backup objects stored in the operator's own Google Drive.

7. Contact

This application is operated privately. Privacy questions can be raised through the project's public repository: github.com/intmeX/vps-backup.
